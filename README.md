# 🦴 傳說中的骨頭

> 一款充滿惡意的搞笑平台跳關遊戲。骨頭在城堡最深處等你，但世界不希望你到達那裡。

---

## 遊戲背景

傳說在世界盡頭的惡魔城堡裡，藏著一根**神聖骨頭**。任何得到它的人，就能成為傳說中的王者。

一個小小的毛茸茸生命決定踏上這段旅程。地圖冷冷地說：「隨你。不過你會死很多次。」

從青翠的草原，穿越背刺的沙漠、打滑的冰雪世界、噴火的活火山、詭異的霓虹都市，最終抵達惡魔城堡——如果你還沒放棄的話。

---

## 角色選擇

開始遊戲後可選擇 4 種角色，每種角色有不同的操控手感：

| 角色 | 名稱 | 特性 | 跳躍 | 速度 |
|------|------|------|------|------|
| 🐶 | 柴犬小汪 | 均衡型・適合新手 | ★★★ | ★★★ |
| 🐱 | 橘貓咪咪 | 快腿型・跳躍稍低 | ★★☆ | ★★★★ |
| 🐰 | 兔子邦邦 | 彈跳型・移速稍慢 | ★★★★★ | ★★☆ |
| 🐼 | 熊貓胖胖 | 笨重型・慢但可愛 | ★★☆ | ★★☆ |

## 操作說明

| 按鍵 | 功能 |
|------|------|
| `← →` 或 `A D` | 左右移動 |
| `↑` 或 `空白鍵` 或 `W` `Z` | 跳躍 |
| `R` | 重試當關（死太多次用的） |
| `← →` | 在選角畫面切換角色 |
| `空白` / `Enter` | 選角畫面確認、劇情畫面跳過 |

## 關卡介紹

遊戲共有 **6 個關卡**，每關開始前有獨立劇情。為了保留遊戲樂趣，這裡只透露主題：

| 關卡 | 標題 | 環境 |

## 平台機關

地圖裡藏了各種**會害死你的平台**，全靠自己摸索：

- **看起來很正常的平台** — 踩了再說
- **搖搖欲墜的** — 你懂的
- **會彈你飛天的** — 不一定是好事
- **超滑的冰面** — 方向盤失靈
- **往下沉的** — 越站越危險
- **傳送帶** — 別問方向
- **會移動的** — 跳上去再後悔
- **假的** — 哈哈哈哈哈

## 敵人

各關卡有不同敵人出沒，牠們都有自己的**嘲諷台詞**，會在攻擊前出言挑釁。具體有哪些、長什麼樣子、怎麼對付——自己去發現。

## 如何遊玩

這是一個純 HTML 單檔遊戲，無需安裝任何軟體：

1. 下載 `index.html`
2. 用任何瀏覽器（Chrome / Edge / Firefox）開啟
3. 點擊遊戲畫面，按任意鍵開始
4. 選好角色，踏上旅程

## 技術資訊

- **平台**：純 HTML5 + Canvas 2D（無框架、無依賴）

- **解析度**：800 × 480
- **瀏覽器支援**：所有現代瀏覽器（Chrome、Edge、Firefox、Safari）
- **檔案命名**：遵循前端 kebab-case 小寫英文命名規範
